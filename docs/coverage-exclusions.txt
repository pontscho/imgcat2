#
# Format (one item per line, '#' comments and blank lines ignored):
#
#   reason: <one-line reason>          applies to every entry that follows, up to the next "reason:" line
#   <file>:<line> <kind>[ <detail>] = <anchor>
#
#   file    path below src/libimg2/
#   line    source line of the item (for items inside a macro expansion: the line of the expansion site)
#   kind    line          the line has an execution count of 0                  (no detail)
#           region        a code region with count 0                            detail = start column
#           branch-true   the true outcome of the condition was never taken     detail = start column
#           branch-false  the false outcome was never taken                     detail = start column
#           function      the function never ran                                detail = function name
#           Inside a macro expansion the detail is "<site column>><line>:<column>" (position in the macro
#           definition, prefixed by its file when the macro lives in another file).
#   anchor  the exact text of the source line, leading/trailing white space stripped: when the code moves,
#           the anchor no longer matches and the checker fails until the entry is re-verified
#
# The checker fails when an uncovered item has no entry, when an entry's item is covered (or gone), when an
# anchor differs from the source, and on syntax errors or duplicates. `scripts/coverage_check.py
# --emit-uncovered` prints every uncovered item in this format.
#
# Reasons starting with "RESOURCE-BOUND" are reachable in principle but need more memory than a unit test can
# use; everything else is unreachable in the measured configuration (all optional codecs except resvg).
